The readout

Eight findings, each tied to the underlying observations.

This report is the narrative half of MacroTrace. It uses eight reproducible comparisons to describe the current U.S. macro backdrop; the dashboard is the exploratory half, with separate Macro and Markets modes so economic levels are never confused with security returns.

Methodology

One row is one observed value on one date.

Sources and rows. Macroeconomic series come from FRED; optional market histories use Yahoo Finance adjusted close. Long-history research indexes use Fama–French monthly returns and Damodaran annual returns with source-file hashes. One row is one series_id, date, value, unit, frequency, source observation, and every series retains its source link.

Cleaning. Header rows, blank or “.” FRED observations, non-numeric values, duplicate dates, and Yahoo rows with null adjusted closes are dropped. Dates remain at their native daily, weekly, monthly, quarterly, or annual frequency; no observations are fabricated between releases.

Comparability. Positive quantities and indexes use (last ÷ first − 1) × 100. Rates use basis-point differences, while signed indexes use point differences. Indexed security views set the first visible adjusted close to 100; standardized macro views show deviations from each series’ own historical mean.

Statistics. Security volatility is the annualized sample standard deviation of log returns using 252, 52, 12, 4, or 1 periods by native frequency. Correlation uses aligned calendar-month changes, or calendar-year changes whenever an annual series is present, and Pearson’s coefficient. Every dashboard calculation runs in the browser from the displayed snapshot.
